This program uses Deep Q-Learning to train a "pirate" agent to find "treasure" in a maze. Much of the code was already written, including the python modules responsible for creating the maze logic and experience that the agent relies on. My contribution was the actual algorithm responsible for training the agent and determining how it will behave.

Computer scientists in the field of machine learning are responsible for designing algorithms in which to train machines that can then behave semi- or fully- autonomously. Research in this field has many potential applications where quick decision-making is important, such as medical diagnostics.

Thinking like a computer scientist means considering the best approaches to handle the problem. There are many types of training algorithms in machine learning, with new ones being developed and refined regularly, and each has uses and drawbacks. Constantly refining my approach, even when the previous one seems to work, is another important element of thinking like a computer scientist.

Ethically, its important to make sure an algorithm and the resulting agent does as little harm as possible. This means making sure that any data used is collected ethically, being as transparent as possible about practices and results, and recovering from failures gracefully.
